# Live AMAs

alternative names: group AMAs, in-person AMAs, collaborative (mini)conference,
resident expert AMA

in a group meeting, people write topics they uniquely know a lot about, then people write
questions they want to ask those people about those topics.
a topic is chosen by the moderator,
and the expert answers the questions and is free to talk more and answer unwritten
follow up
questions. people could learn about a topic beforehand specifically so they have
something to share, in which case they get priority.

between unstructured conversation (noisy) and a conference (a lot of prep work)

share bitly link on paper w/ marker


# How to run

1.  `git clone https://github.com/amacfie/LiveAMA.git`
1.  `cd LiveAMA`
1.  `nix-shell`
1.  `uvicorn main:app --host 0.0.0.0 --port 8000`
